Thmanyah font files live under this folder and are served by Next.js from `/assets/fonts/thmanyah/**`.

Detected families:

- Thmanyah Sans
- Thmanyah Serif Display
- Thmanyah Serif Text

Preferred formats:

- woff2 (used by `src/app/globals.css`)

Note: `src/app/globals.css` applies Thmanyah Sans only when Arabic is active, so English continues to use Manrope/system UI fonts.
